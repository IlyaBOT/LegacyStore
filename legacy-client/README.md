# LegacyStore Legacy Client

Placeholder for the future Objective-C/AppKit client.

The Xcode project and source skeleton are intentionally not created in this
task. Task 7 must add them while preserving these constraints:

- Objective-C and AppKit only;
- no Swift;
- no SwiftUI;
- no Storyboards;
- no ARC as a hard dependency;
- target Mac OS X 10.5 through macOS 10.15 Intel;
- target architectures `i386` and `x86_64`.
